Carryall

Carryall tools are single HTML files that hold structured data, a viewer and an editor. Open a tool, add your data and download a copy. The copy works on its own, anywhere, with no server.

Build your own tool

A tool is defined by a short JSON tool definition (tables, columns, spreadsheet-like formulas and views), or for complex tools by a JavaScript app. Carryall checks every part of a definition and explains each problem in plain words, so an AI assistant can write it and fix it.

  1. Describe itTell an assistant what you want to keep track of and calculate.
  2. Check itThe checker lists any problems for the assistant to fix, until the tool passes its self-test.
  3. Try itPreview the tool: add and edit rows and check the numbers.
  4. Share itYour finished tool is one HTML file. Share it, or have it hosted.

With GitHub Copilot in VS Code

Copilot's agent edits the tool file, runs the checker and fixes problems itself. It writes a tool definition for simpler tools and a JavaScript app for complex ones.

Try the saved-copy workflow

  1. Download the old v1 copy of the asset register and open it from your computer in Edge or Chrome. It works on its own and shows a banner pointing to the latest version.
  2. Select Open data in latest tool. The hosted tool opens and loads the data, upgrading it from schema 1 to schema 3.
  3. Make a change and select Download. You get a new copy with your data and the latest tool inside it.

Everything runs in your browser. Nothing you enter is uploaded; data leaves the page only as a file you download.

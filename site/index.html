Carryall tools are single HTML files that hold structured data, a viewer and an editor. Open a tool, add your data and download a copy. The copy works on its own, anywhere, with no server.

Try the saved-copy workflow

  1. Download the old v1 copy of the asset register and open it from your computer in Edge or Chrome. It works on its own and shows a banner pointing to the latest version.
  2. Select Open data in latest tool. The hosted tool opens and loads the data, upgrading it from schema 1 to schema 3.
  3. Make a change and select Download. You get a new copy with your data and the latest tool inside it.

Everything runs in your browser. Nothing you enter is uploaded; data leaves the page only as a file you download.
